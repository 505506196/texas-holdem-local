# 德州扑克 · 本地版

一个零依赖的单机德州扑克练习工具。双击 `index.html` 即可开始，不联网、不上传任何数据。

除了打牌，它的重点是**手牌复盘**：每一手结束后可以逐个决策点查看你的胜率、底池赔率门槛、各选项的期望值对比，以及这手牌涉及的战术原则。

## 功能

- 2 到 8 人同桌（1 到 7 个 AI 对手），起始筹码与盲注等级可选
- 涨盲：每 5 / 10 / 20 手盲注翻一倍（10/20 → 20/40 → 40/80），也可关闭
- 单挑加速：只剩两家时盲注改为每手翻倍，避免收官被小盲注拖成拉锯（关闭涨盲时不生效）
- 大盲前注：大盲位额外垫 1 或 2 倍大盲当底池，别人无需跟这笔钱，也可关闭
- 完整四轮下注：弃牌 / 过牌 / 跟注 / 下注 / 加注 / 全下，支持边池切分
- 四种 AI 性格：紧手、稳健、松凶、跟注站
- 左侧行动记录分「本手」与「历史牌局」两段
- 弃牌后可一键跳过本手，加快节奏
- 摊牌时赢家座位金色高亮 + 🏆 角标、底牌镶金边，牌型名赢家金色/败家暗灰，一眼看出谁的牌大
- 手牌复盘：范围加权胜率、多动作 EV 对比、17 条战术规则检查

## 运行

不需要构建，不需要安装依赖。

```
双击 index.html
```

或者起一个本地服务（某些浏览器对 `file://` 有限制时用）：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 复盘功能说明

这部分是这个项目和普通扑克小游戏的区别所在，也是最需要说清楚边界的地方。

### 它做什么

每个决策点会给出四组信息：

1. **胜率** — 蒙特卡洛模拟 3000 次。对手底牌不是随机发的，而是枚举全部候选组合后，按他每街的动作和下注尺度逐一加权。下注加注会抬高该牌面上成牌与强听牌的权重、压低中等牌；过牌相反；大注让范围更极化，小注让范围更宽。
2. **底池赔率门槛** — `跟注额 ÷ 跟注后底池`，即跟注长期不亏所需的最低胜率。
3. **各选项期望值** — 弃牌、过牌或跟注、下注或加注三行并列，口径统一为净收益，可直接横向比较。最优项高亮，你的实际选择会标注。
4. **战术原则** — 命中的规则会显示原则名，面板底部汇总本手涉及的全部原则。

### 它不是 GTO 求解器

真正的 GTO 需要求解纳什均衡（CFR 一类算法），是范围对范围的博弈，计算量远超浏览器实时能力。这里做的是**范围加权的剥削性分析**（exploitative analysis）：假定对手按其表现出的倾向持牌，然后算出针对这个假定的最优反应。

它能可靠抓出业余局里最常见的漏钱点——该弃牌却跟注、胜率够却弃牌、强牌只跟不加、被动方反主动下注、牌面有 A 时高估超对——但它给的不是均衡解。

### 精度分级（重要）

EV 表里各行的可信度不同，读的时候要区别对待：

| 行 | 可信度 | 原因 |
|---|---|---|
| 弃牌 | 精确 | 恒为 0 |
| 跟注 / 过牌 | 高 | 封闭公式，只依赖胜率估计 |
| 下注 / 加注 | 中 | 依赖弃牌率与被跟注后胜率两个派生量 |

下注行标注「实测」时，被跟注后的胜率是真算的：派生出对手会跟注的子范围（按各强度档的续注概率剔除弱牌），再对这个子范围重跑一次模拟。标注「估算」时说明范围数据不足，退回了经验系数。

所以下注行该看的是**正负号和量级**，不是具体数值。`+44` 和 `+38` 的差别没有意义，`+44` 和 `−125` 的差别才有意义。

另外，蒙特卡洛 3000 轮在胜率 40% 附近的标准误约 ±0.9%，95% 置信区间约 ±1.8%。面板显示到小数位是为了看趋势，小数本身是噪声。

## 项目结构

```
index.html          界面骨架
css/styles.css      样式
js/cards.js         牌、洗牌、牌型评估（7 选 5 穷举）
js/preflop.js       翻前范围：169 手强度序、位置范围表、座位映射
js/strategy.js      翻后工具：MDF、牌面 5 分类、SPR 分档、河牌极化
js/game.js          游戏状态机：发牌、下注轮、边池、结算、涨盲
js/ai.js            AI 决策：位置范围 + 牌面分类尺度 + MDF 防守 + SPR
js/range.js         对手范围建模：牌面感知加权、续注概率
js/review.js        复盘：范围加权胜率、EV 计算、战术规则引擎
js/app.js           UI 渲染与交互
```

### AI 的职业级策略（js/preflop.js + js/strategy.js）

在原有的 Chen 公式 + 底池赔率之上，AI 现在按职业框架决策：

- **位置分级翻前范围** — 6 个位置（UTG/MP/CO/BTN/SB/BB）各有标准开池、3bet、跟注范围。用一份 169 手强度序 + 每位置一个百分比阈值、按组合数（1326）累加取前 N%，而非手写枚举。UTG 只开约 15%，BTN 开约 43%。2-8 人局自动映射到这套语义。
- **牌面 5 分类** — 干燥高牌面 / 湿润同花面 / 成对面 / 顺子面 / 彩虹安全面，每类对应标准持续下注频率与尺度（湿面下大注收保护费，成对面小注控池）。
- **MDF 最小防御频率** — 面对小注时按 MDF 防守，避免被对手用任意两张无风险剥削。
- **SPR 筹码深度分档** — SPR<1 只推/弃，深筹码才多尺度下注。
- **河牌极化** — 中间强度牌一律过牌，只用坚果价值下注 + 空气诈唬。

同样，这是启发式的剥削性打法，不是 Solver 均衡解。它不做跨手的对手建模（本项目对手性格每局随机、无持久身份，统计无意义）。

## 已知局限

- **对手范围的翻前部分仍用 Chen 公式筛选**。Chen 分是起手牌指标，无法表达位置差异，翻前范围的精度上限受此限制。
- **隐含赔率用经验常数**。每张补牌每街按约 2% 命中率、击中后按多收半个底池估算，实际取决于对手筹码深度与支付意愿。
- **多人底池的胜率折价是线性近似**。每多一个对手按固定百分比下调门槛，没有建模多人局的范围交互。
- **无存档**。刷新页面会重开，牌局历史不持久化。
- **涨盲只支持翻倍**。到点乘 2，不支持自定义盲注结构。单挑后每手翻倍，几手内盲注就会吃光筹码——这是有意为之的收官加速，不是失控。
- **前注只收大盲位**。采用锦标赛的大盲前注（BB ante）形式，不支持全员各付一份的传统 ante。大盲筹码不够时前注会被削减到余额，且先保大盲注、再付前注——与 WSOP 的「前注优先」相反，为的是避免出现没下大盲就全下的局面。
